---
name: Projection access checks
description: Avoid mistaking public preview tables and old free-projection documentation for a complete export.
---

Verify the actual current projection row limit and permitted export mechanism, not just filter options, search snippets, or an older user guide.

**Why:** The 2026–27 Hashtag projection page exposed only 30 free players even though it offered an “All” filter and its user guide described free projections. Other publicly readable forecast tables lacked explicit shooting makes or attempts. Such tables cannot safely replace a full draft pool.

**How to apply:** Recheck current access each season. Confirm full-player coverage, forecast dates and explicit shooting volumes before conversion. If membership is required, request a provider-permitted user export rather than bypassing access restrictions. Do not promise that buying membership includes CSV export unless verified.

Public provider statistics can use sparse zero serialization, so strict missing-column logic can silently exclude important zero-three-point centers.

**Why:** ESPN's full-season forecast profiles omitted the made-threes key for players including Gobert, Duren and Allen. Their explicit integer PTS, FGM and FTM season totals independently proved zero threes. Other missing statistics did not have that independent evidence.

**How to apply:** Do not default every absent provider field to zero. Accept a derived zero only with independent exact-stat evidence, not rounded percentages or historical stats; retain a regression check that zero-three centers remain draftable. Distinguish the provider's raw profile count from the validated projection pool.
