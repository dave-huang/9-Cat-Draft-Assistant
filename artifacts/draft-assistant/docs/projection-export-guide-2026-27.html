Export checklist

  1. Open Projections, not historical Player Rankings. Select the 2026–27 full-season/preseason forecast, not daily, weekly or historical actuals.
  2. Choose per-game averages. Include projected season games as a separate column.
  3. Choose Yahoo as the fantasy provider if supported. Include Yahoo position eligibility and Yahoo ADP if available.
  4. Select the complete player pool, with no team, position or top-30/top-50 filter. The default 12-team, 13-slot draft has 156 picks; include additional alternatives.
  5. Include the raw forecast stats listed above. Provider ranks, fantasy points and DURANT values are not a substitute. Leave every category enabled; the assistant keeps its no-punt approach.
  6. Use the provider’s Excel or CSV export control. If a supposed CSV opens as a spreadsheet, keep the original file rather than changing its extension. A member reported this behavior on Basketball Monster’s forum.
  7. Save the source name, forecast update date, season, selected platform and units. If no forecast date is published, record it as unknown; download time is not forecast time.
  8. Upload the authorized export for conversion and validation. Any missing required stats or uncertain Yahoo eligibility must be resolved explicitly before real-draft use.

Exact import format

name,team,positions,games,points,rebounds,assists,steals,blocks,threes,turnovers,fgm,fga,ftm,fta,adp,note

This is the header contract—not an import-ready file. The app requires at least one valid player and adequate full-draft coverage.

App fieldRequired source meaning
name, teamPlayer name and forecast team; resolve identity conflicts rather than guessing.
positionsYahoo-verified PG, SG, SF, PF or C, separated by slash; e.g. PG/SG. Do not expand generic G/F into assumed eligibility.
gamesExpected 2026–27 season games, 1–82; not last season’s games or an invented 82.

threes, turnoversProjected per-game made three-pointers and turnovers, not three-point attempts or assist/turnover ratio.
fgm, fga, ftm, ftaExplicit projected per-game field-goal and free-throw makes and attempts. Do not reconstruct from rounded percentages.
adpOptional positive Yahoo ADP. Leave blank if absent; do not substitute rank or blended-platform ADP.
noteOptional source/date/season details and dated availability caveats, at most 1,000 characters.

If the export contains explicit forecast totals and projected GP, dividing totals by GP is a documented unit conversion. It cannot supply a forecast field the source never provided. Never silently fill missing required values with zero or historical averages.

After conversion: import safely

  1. Validate the converted CSV with the app’s existing parser. It checks unique names, required values, legal positions, bounds and shooting makes not exceeding attempts. Passing this check does not certify forecast accuracy.
  2. Open Settings → Projections source. Enter the provider and forecast date in Source label, and 2026–27 in Season.
  3. Select the validated CSV and click Import and replace pool. Import replaces the entire player pool; do not use a partial preview.
  4. If you have recorded picks, first use Export session JSON to make a backup. Replacing projections requires an empty draft and an explicit pick reset. Do not reset without preserving a backup.
  5. Check the player count, source, eligibility and availability notes. All nine categories remain positively weighted; no Yahoo synchronization or automated picks are added.
